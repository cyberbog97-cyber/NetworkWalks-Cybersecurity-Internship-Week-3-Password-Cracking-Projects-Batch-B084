# NetworkWalks Cybersecurity Internship – Week 3
## Password Cracking Projects | Batch B084

Welcome to my Week 3 practical projects completed as part of the NetworkWalks Cybersecurity & Ethical Hacking Internship.

This week's activities focused on password cracking, hash extraction, and password security testing using John the Ripper and NetworkWalks tools.

## 📌 Project Overview

### Project Module 1: Password Cracking with John the Ripper (JTR)

**Tools Used:**
- John the Ripper
- Johnny GUI
- Online PDF Hash Extractor
- Notepad

**Tasks Performed:**
1. Installed and configured John the Ripper and Johnny GUI.
2. Extracted the password hash from an encrypted PDF.
3. Saved the extracted hash in a text file.
4. Loaded the hash into Johnny.
5. Started a password-cracking attack.
6. Successfully recovered the password.
7. Verified the recovered password by opening the protected PDF.

### Project Module 2: Password Cracking with NetworkWalks Tools

**Tools Used:**
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Web Browser

**Tasks Performed:**
1. Uploaded the protected PDF to the Hash Calculator.
2. Extracted and copied the PDF hash.
3. Submitted the hash to the Password Cracker.
4. Executed the password recovery process.
5. Successfully recovered the password.
6. Verified access to the protected PDF.

## 🎯 Key Learning Outcomes

- Understanding password-cracking methodologies.
- Learning how password hashes are extracted.
- Gaining practical exposure to John the Ripper.
- Working with graphical password-cracking interfaces.
- Understanding the importance of password complexity.
- Recognizing the role of password security testing in ethical hacking.
